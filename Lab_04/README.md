## Рекурсія та мемоізація в Python

**Варіант 11 — Задача про сходинки**

### Мета роботи

Навчитися використовувати рекурсію та мемоізацію в Python,
дослідити швидкість рекурсивних та ітеративних алгоритмів.

### 1. Опис задачі

Потрібно визначити кількість способів піднятися на n сходинок,
якщо за один крок можна подолати 1, 2 або 3 сходинки.

Формула:

f(n) = f(n-1) + f(n-2) + f(n-3)

Базові випадки:

- f(0) = 1
- f(n) = 0, якщо n < 0

### 2. Реалізації

У програмі реалізовано три способи розв'язання задачі:

- stairs_naive — звичайна рекурсія без кешування;
- stairs_memo — рекурсія з використанням lru_cache;
- stairs_iter — ітеративний алгоритм.

### 3. Мемоізація

Для збереження результатів використовується декоратор:

@lru_cache(maxsize=None)

Він запам'ятовує результати функції для однакових аргументів.

Для перегляду інформації про кеш використовується:

stairs_memo.cache_info()

Для очищення кешу:

stairs_memo.cache_clear()

### 4. Аналіз складності

- Звичайна рекурсія має експоненційну часову складність O(3^n).
- Рекурсія з мемоізацією має часову складність O(n).
- Ітеративна реалізація має часову складність O(n) та додаткову пам'ять O(1).

### 5. Обмеження рекурсії

У Python існує обмеження глибини рекурсії, яке можна перевірити за допомогою:

import sys
print(sys.getrecursionlimit())

У CPython стандартний ліміт зазвичай становить приблизно 1000 викликів.

При перевищенні цього обмеження виникає RecursionError.

У CPython відсутня оптимізація хвостової рекурсії (TCO).
Це означає, що навіть хвостові рекурсивні виклики продовжують використовувати стек.

Ітеративний алгоритм безпечніший для великих значень n,
оскільки не створює великої кількості рекурсивних викликів.

### 6. Порівняння часу виконання

Для порівняння реалізацій створено файл benchmark.py.

Він вимірює час роботи трьох алгоритмів для n = 10, 20 та 25.

Результати виводяться у вигляді таблиці в терміналі.

Звичайна рекурсія працює повільніше, оскільки повторно обчислює однакові підзадачі.

Мемоізована та ітеративна реалізації працюють значно швидше.

### 7. Тестування

Для тестування використовується бібліотека pytest.

Тести перевіряють:

- правильність обчислень;
- базові та граничні випадки;
- відповідність результатів трьох реалізацій;
- роботу кешу;
- правильність QuickSort;
- обходи бінарного дерева;
- обчислення чисел Фібоначчі.

### 8. Запуск проєкту

Встановлення залежностей:

pip install -r requirements.txt

Запуск тестів:

python -m pytest -q

Запуск порівняння часу:

python benchmark.py
